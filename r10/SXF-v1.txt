Scalar Exchange Format (SXF) Version 1

Basic SXF Record

0x00      0x01                                                             0x1F
┌──────────┬────────────────────────────────────────────────────────────────────┐
│  Header  │                           Payload Data                             │
│ (1 Byte) │                       (31 Bytes / 248 Bits)                        │
└──────────┴────────────────────────────────────────────────────────────────────┘

Basic Header Bit Layout (Byte 0x00):
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ 7 │ 6 │ 5 │ 4 │ 3 │ 2 │ 1 │ 0 │
└───┴───┴───┴───┴───┴───┴───┴───┘
  └─── Version ───┘   └───┘   └── Extension Flag (0 = 1B Header, 1 = 2B Header)
      (Bits 7-3)        Encoding (Bits 2-1)
                         00 = Binary Cardinal
                         01 = Binary Integer
                         10 = Scaled Binary
                         11 = Scaled Decimal

Encoding 0b00 - Binary Cardinal

 0x01                                                               0x1F
┌───────────────────────────────────────────────────────────────────────┐
│              Contiguous, Unsegmented Raw Unsigned Binary              │
└───────────────────────────────────────────────────────────────────────┘
 └────────────────────────── 31 Bytes / 248 Bits ──────────────────────┘

 Maximum Range: 0 to (2^248 - 1)
 Maximum Decimal Digits (Input): 74 digits
 Maximum Decimal Digits (Output): 75 digits

┌───────────────────────────────────────────────────────────────────────┐

 └────────────────────────── 31 Bytes / 248 Bits ──────────────────────┘

 Maximum Range: -2^247 to (2^247 - 1)
 Maximum Decimal Digits (Input): 74 digits
 Maximum Decimal Digits (Output): 75 digits

┌─────────────────────────┬─────────────────────────────────────────────┐

 └── 2 Bytes / 16 Bits ──┘ └─────────── 29 Bytes / 232 Bits ───────────┘

 Maximum Exponent Range: 2^-32768 to 2^32767

Extended SXF Record

 0x00      0x01       0x02                                                  0x3F       
┌─────────────────────┬─────────────────────────────────────────────────────────┐
│   Extended Header   │                Payload Data                             │
│      (2 Bytes)      │            (62 Bytes / 496 Bits)                        │
└─────────────────────┴─────────────────────────────────────────────────────────┘

Extension Header Bit Layout (Byte 0x01):
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ 7 │ 6 │ 5 │ 4 │ 3 │ 2 │ 1 │ 0 │
└───┴───┴───┴───┴───┴───┴───┴───┘
  └───┘   └──── Reserved ─────┘ 
   Payload Size (Bits 7-6)
    00 =  496 Bits  10 = Reserved
    01 = Reserved   11 = Reserved
